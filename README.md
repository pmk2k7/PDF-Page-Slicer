PDF Page Slicer (PDFSlicer.py)Tkinter மற்றும் PyPDF2 நூலகங்களைப் பயன்படுத்தி, பெரிய PDF கோப்புகளில் இருந்து குறிப்பிட்ட பக்கங்களை மட்டும் (Page Range) எளிதாகத் வெட்டிப் பிரித்தெடுக்க (Slice) உதவும் எளிய வரைகலை (GUI) பயன்பாடு ஆகும்.   🚀 முக்கிய அம்சங்கள் (Key Features)PDF கோப்புத் தேர்வு (PDF Selection): உங்கள் கணினியில் உள்ள எந்தவொரு PDF கோப்பையும் எளிதாகத் தேர்ந்தெடுக்கலாம்.   வெளியீட்டு அடைவுத் தேர்வு (Output Folder Selection): வெட்டப்பட்ட புதிய PDF கோப்பு எங்கு சேமிக்கப்பட வேண்டும் என்பதைத் தேர்ந்தெடுக்கலாம்.   பக்க வரம்பு உள்ளீடு (Page Range Input): தொடக்கப் பக்கம் (Start Page) மற்றும் முடிவுப் பக்கத்தை (End Page) உள்ளிட்டு குறிப்பிட்ட பகுதிகளை மட்டும் தனிமைப்படுத்தலாம்.   தானியங்கிப் பாதுகாப்பு & சரிபார்ப்பு (Validation): தவறான பக்க எண்கள் அல்லது காலியான இடங்களைக் கண்டறிந்து தகுந்த பிழைச் செய்திகளை (Error Messages) வழங்கும்.   புதிய கோப்பு உருவாக்கம்: தேர்ந்தெடுக்கப்பட்ட பக்கங்களை மட்டும் கொண்டு sliced_[original_filename] என்ற பெயரில் புதிய PDF கோப்பை உருவாக்கும்.   📦 தேவையான நூலகங்கள் (Prerequisites)இந்த நிரலை இயக்க உங்கள் கணினியில் பைத்தானுடன் பின்வரும் நூலகம் நிறுவப்பட்டிருக்க வேண்டும்:Bashpip install PyPDF2
🛠️ பயன்பாடு (How to Use)இந்த பைத்தான் நிரலை இயக்கவும்:Bashpython PDFSlicer.py
திறக்கும் வரைகலை சாளரத்தில் (GUI Window):Browse பொத்தானைக் கிளிக் செய்து நீங்கள் பிரிக்க வேண்டிய PDF கோப்பைத் தேர்ந்தெடுக்கவும்.   வெளியீட்டுக்கான கோப்புறையைத் (Output Folder) தேர்ந்தெடுக்கவும்.   Start Page மற்றும் End Page பெட்டிகளில் நீங்கள் பிரித்தெடுக்க விரும்பும் பக்க எண்களை உள்ளிடவும்.   "Slice PDF" பொத்தானைக் கிளிக் செய்து புதிய PDF கோப்பை உருவாக்கவும்.   💻 நிரல் குறியீட்டு அமைப்பு (Code Structure)PDFSlicerApp வகுப்பு: முழுமையான வரைகலை இடைமுக வடிவமைப்பு மற்றும் கோப்பு மேலாண்மைக் கட்டுப்பாடுகளைக் கொண்டுள்ளது.   browse_pdf & browse_output முறைகள்: கோப்புகள் மற்றும் கோப்புறைகளைத் தேர்ந்தெடுக்க வழிவகை செய்கிறது.   slice_pdf முறை: உள்ளீடுகளைச் சரிபார்த்து, PyPDF2 உதவியுடன் குறிப்பிட்ட பக்கங்களை மட்டும் தனியாகப் பிரித்து புதிய கோப்பாகச் சேமிக்கிறது.
